We are researching on priority-aware task scheduling mechanism to maintain critical house activities under ZESA Load- Shedding Schedules

RESEARCH QUESTION
How can an automated, priority-aware domestic task scheduling algorithm dynamically optimize household appliance runtimes to maximize the completion of critical operations and minimize grid reliance under unpredictable ZETDC load-shedding schedules?

**_AIMS_**:
      1. Build a prototype that simulates how power is distributed according to its priority as a household task.



DELIVERY METHOD

The final output of this project will be a priority-aware household task scheduling system prototype that uses ZETDC load shedding schedules to classify and grade household activities according to their level of importance.
The system will automatically prioritize critical tasks, such as food preservation, water pumping, device charging, and essential appliances, and schedule them during available electricity periods.
Here are the links for the data sources to be used...Data sources:

1. UCI Machine Learning Repository – Individual Household Electric Power Consumption dataset (primary energy-consumption proxy).
2. Kaggle – Electric Power Consumption dataset (alternative access to the UCI dataset).
3. Google Cluster Data (GitHub) – supplementary computing-workload traces for understanding task scheduling.
4. Publicly available ZETDC/ZESA load-shedding schedules for the Zimbabwean context.
